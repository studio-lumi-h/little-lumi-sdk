Little LUMI Model — Mod SDK

This SDK exists so that owners of Little LUMI Model can build plugins for it.
It contains (a) compiled jars of the app and its libraries, provided for
COMPILING plugins only, (b) a build tool and example plugins, (c) the API
reference (docs/: the public API source files, their javadoc, the guide, the catalogue).
