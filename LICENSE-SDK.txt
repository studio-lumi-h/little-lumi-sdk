Little LUMI Model — Mod SDK

This SDK exists so that owners of Little LUMI Model can build plugins for it.
It contains (a) compiled jars of the app and its libraries, provided for
COMPILING plugins only, (b) a build tool and example plugins, (c) the API
reference (docs/: the public API source files, their javadoc, the guide, the catalogue).

========================================
Little LUMI 모드 SDK 이용 조건
========================================

1. 이 SDK(소스·jar·도구·예제)는 Little LUMI 용 모드를 만드는 목적에만 쓸 수 있습니다.
2. SDK 자체를 다시 배포하거나, 이 SDK 로 Little LUMI 를 대체·우회하는 실행물을 만드는 것은
   금지합니다.
3. 만든 모드는 스팀 창작마당이나 다른 곳에 무료로 공개할 수 있습니다. 모드를 판매하거나
   유료 접근 뒤에 두는 것은 금지합니다.
4. 모드에 SDK 의 소스나 jar 가 포함되어도 됩니다. 단 그 안의 루미 캐릭터·이름·그림·대사에
   대한 권리는 STUDIO LUMI 에 있습니다.
4-2. 루미의 그림·대사를 바탕으로 한 파생물(의상·표정·포즈·이미지셋·대사 조각 등)은
   Little LUMI 안에서 쓰는 모드로 만들어 3항의 조건(무료 공개)으로 창작마당이나 다른 곳에
   공개할 수 있습니다. 그 파생물을 Little LUMI 밖의 다른 제품·상품·굿즈에 쓰는 것, 그리고
   루미의 이름·모습을 성적·혐오·정치적 표현이나 STUDIO LUMI 를 사칭하는 데 쓰는 것은
   별도 허락 없이는 금지합니다.
5. 모드가 일으킨 문제에 대해 STUDIO LUMI 는 책임지지 않으며, 모드 제작자가 책임집니다.
   사용자 개인정보를 다루는 모드는 그 사실을 설명에 밝혀야 합니다.
6. 스톡 엔진(Shimeji-ee)에서 온 부분은 원래 라이선스를 따릅니다(docs/licenses/THIRD_PARTY_LICENSES.txt 참조).
7. 이 조건은 예고 후 바뀔 수 있으며, 바뀐 뒤 받은 SDK 부터 적용됩니다.
