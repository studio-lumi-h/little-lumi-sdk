1. 행동 이름 — ctx.behave(name) · ctx.behaviorNames(imageSet)

img\Lumi\conf\behaviors.xml 의 <Behavior Name> 전부와 행동목록.txt 의 한글 이름입니다. 다른 이미지셋은 제 behaviors.xml 을 따르므로 실행 중에는 ctx.behaviorNames(imageSet) 이 정답입니다. 기부 점프 JumpDono_x<0..9>_y<0..14> 150개는 좌표별로 생성된 것이라 한 줄로 접었습니다.

숨김(Hidden="true")은 캐릭터 메뉴에서 감출 뿐입니다. 저절로 골라지는지는 빈도와 Condition 이 정합니다 — 빈도는 선택 가중치이지 시간이나 고정 확률이 아니고, 0 이면 자동 선택에서 빠지지만 이름으로 부르거나 다른 행동에서 이어질 수는 있습니다. 숨김이면서 빈도 > 0 인 행동도 있습니다. 토글(Toggleable="true")은 숨김과 같이 붙을 수 있습니다. Dragged·Thrown 은 엔진이 마우스 조작으로 거는 행동입니다.

2. 이벤트 토픽과 페이로드 — ctx.on(topic, event -> …)

「실험」 칩이 붙은 항목은 api_version 을 올리지 않고 바뀌거나 없어질 수 있습니다(같은 목록이 sdk.json 의 preview 에 있습니다). 표시가 없는 항목은 안정입니다 — API.md §8.

따로 형을 적지 않은 값은 문자열입니다. mascotId 는 그 개체가 사는 동안만 유효하고(사라지면 재사용될 수 있습니다), 좌표는 바탕화면 좌표입니다. 앱에서는 플러그인마다 하나인 이벤트 스레드에서, 테스트 킷에서는 부른 스레드에서 리스너가 돕니다. 페이로드 예시와 연동 주의점은 API.md 의 이벤트 절 을 보세요.

3. 훅과 ctx 키 — ctx.hook(id, (hook, current, ctx) -> …)

「실험」 칩이 붙은 항목은 api_version 을 올리지 않고 바뀌거나 없어질 수 있습니다(같은 목록이 sdk.json 의 preview 에 있습니다). 표시가 없는 항목은 안정입니다 — API.md §8.

PluginHooks.KNOWN 의 id 마다 코어가 묻는 자리(앱 소스의 파일 — 여럿이면 · 로 잇습니다), 묻는 메서드, 기본값 식, ctx Map 의 키입니다. 소스 경로는 어디서 묻는지 알려 주는 참고이고 그 파일이 SDK 에 들어 있지는 않습니다. 반환형·범위·특수값은 API.md 의 훅 표 를 먼저 보세요. null 은 통과(앞선 current 유지)이고, 뒤의 핸들러가 null 아닌 값을 돌려주면 앞선 답을 바꿉니다. 훅 안에서는 파일·네트워크·잠금을 잡지 마세요.

5. 앱 설정 키 — ctx.setting(key, fallback) (읽기만)

● = Preferences.KEYS(스팀 클라우드에 오르는 취향 값, conf\preferences.properties 에도 사본). 나머지는 앱이 conf\settings.properties 에 실제로 읽고 쓰는 키입니다 — 앱 소스에서 설정 저장소(LumiSettings)를 지나는 자리에서만 모았습니다. 값은 전부 문자열이고 앱 버전마다 늘 수 있으며, 표에 실렸다고 고정 계약이 되지는 않습니다.

대응하는 공개 조회 메서드가 없을 때만 ctx.setting(key, fallback) 으로 읽고 없는 경우를 처리하세요 — 언어는 language(), 활성 셋은 activeImageSets(), 기능은 featureEnabled(id) 입니다. 플러그인은 앱 키를 쓰지 않습니다 — 제 것은 ctx.prefs() 에 둡니다.
