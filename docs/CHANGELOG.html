Little LUMI Model — 플러그인 API 변경 이력 / Plugin API changelog

플러그인이 기대도 되는 표면(API.md)이 앱 버전마다 어떻게 바뀌는지 여기에 적습니다 — 더한 것은 「추가」, 기본값만 돌려주는 빈 자리가 된 훅은 「폐기」. 실험 항목(「실험」 칩, sdk.json 의 preview)의 변경과 폐기도 여기에 적습니다. Per app version: what changed in the surface a plugin may rely on (API.md) — "Added" for additions, "Deprecated" for a hook that became an empty default-only slot. Changes to and removals of preview items (the "preview" chip, preview in sdk.json) are listed here too.

SDK 1.5.0 · 앱 1.5.0 · api_version 1 — 현재 배포 / Current distribution

api_version은 1을 유지하며 기존 안정 API를 계속 지원합니다. 아래 캐릭터 제작·미리보기·지형 API는 실험 항목입니다. / api_version remains 1 and existing stable APIs remain supported. Character authoring, preview and terrain APIs below are preview features.

캐릭터 제작 / Character authoring

  • VisualLogic·CharacterDefinition으로 시각 규칙과 자체 캐릭터를 생성하고, CharacterTemplates로 행동·공유 액션·모션 템플릿을 조회할 수 있습니다. 독립 내보내기는 본체 안내 이미지·원음을 포함하지 않습니다. / Generate visual rules and original characters, query behavior/action/motion templates, and export standalone characters without host guide images or sounds.
  • 45종의 자동 애니메이션으로 이동·벽·천장·착지·앱 반응과 캐릭터 간 상호작용을 구성할 수 있습니다. 최소 실행 프로필은 사용자 모션과 최대 2초의 종료 반응을 지원합니다. / Configure 45 automatic animations for movement, terrain, app reactions and social activities. Minimal profiles support custom motions and exit reactions of up to two seconds.
  • 프레임별 WAV·무음·반복·음량과 SoundPlayback 재생 범위를 지원합니다. validSoundPath는 Unicode·공백이 있는 상대 경로를, validAutomaticImageSetName은 자동 캐릭터 폴더 이름을 검사합니다. / Added per-frame WAV, silence, looping, gain and playback scope, plus Unicode/space-aware sound-path and automatic character-folder validation.
  • HeldMotion.PHYSICS로 잡았을 때의 연속 물리 회전을 선택할 수 있습니다. 기존 생성 호출은 기존 동작을 유지하며, MascotState.bounds는 회전 후 표시 영역을 반환합니다. / Opt into continuous held rotation with HeldMotion.PHYSICS; existing generation calls keep their behavior. MascotState.bounds reports the rotated display area.
  • 자동 캐릭터의 창 옆면 접촉 위치, 선물 받기 후 대기·종료, 행동 전환 뒤 효과음 정리를 개선했습니다. / Improved window-edge alignment, finite gift waiting/end sequences and sound cleanup after behavior transitions.
  • HelperVisuals와 5인자 생성 오버로드는 이전 자동 출력의 비교·복원을 위한 호환 API입니다. 새 제작과 실제 미리보기에는 기존 생성·미리보기 API를 사용하세요. / HelperVisuals and five-argument generation overloads support historical-output comparison/recovery; use the existing generation and preview APIs for new work.

미리보기와 지형 / Preview and terrain

  • AuthoringPreview로 실제 엔진에서 1–3마리의 임시 캐릭터를 시험하고 구성·규칙·변수를 확인할 수 있습니다. AnimationActivities로 연계 단계·역할·대체 그림을 조회하고 활동을 시작·일시정지·중지할 수 있습니다. / Test 1–3 temporary engine characters, inspect configuration/rules/variables, query linked stages/roles/visuals, and start, pause or stop activities.
  • registerTerrain, TerrainRect, TerrainHandle로 발판을 등록·갱신·해제할 수 있습니다. examples/terrain-basic에서 사용법을 확인하세요. / Register, update and remove platforms; see examples/terrain-basic.

창작마당과 플러그인 UI / Workshop and plugin UI

  • PluginContext.workshopPublisher()로 사용자 확인 후 모드를 게시·갱신할 수 있습니다. 계정·소유권을 검사하고, 업데이트의 기존 공개 범위를 유지하며, 실패한 신규 게시를 같은 항목으로 재시도할 수 있습니다. / Publish/update after user confirmation, with account/ownership checks, preserved update visibility and retries using the created item ID.
  • WorkshopPublisher.Request에 파일 목록·미리보기 SHA-256 검증을 추가했습니다. Listener.sourceReleased()로 임시 원본 파일을 정리할 시점을 알 수 있습니다. 기존 8인자 요청도 계속 지원합니다. / Added exact file/preview hash verification and a source-release callback for temporary-file cleanup, while preserving eight-argument requests.
  • MenuHandle.setLabel 변경이 이미 표시 중인 메뉴·설정 단추에도 반영됩니다. 설정 카탈로그에 PomodoroCycles, lumi.reminder.sound.*, lumi.reminder.speaker를 추가했으며, 포모도로는 지정한 주기 완료 시 phase=stopped를 한 번 발행합니다. / Label changes reach visible menu/settings controls. Added cycle-count and reminder audio settings; Pomodoro emits one stopped phase when the configured cycles finish.

SDK 1.4.0 · 앱 1.4.0 · api_version 1

  • WorkshopContent의 제작자 파일·구독 식별자 조회를 안정 API로 추가했습니다. / Added stable WorkshopContent queries for creator files and subscription identities.
  • 재시작은 app 이벤트의 phase=restart로 구분합니다. phase=exit는 일반 종료입니다. 재시작에는 인사 연출을 생략하고 필수 저장·해제는 두 경우 모두 stop()에서 수행합니다. / Restarts publish app with phase=restart; normal exit uses phase=exit. Skip farewell presentation on restart and perform required persistence and cleanup in stop() for both phases.
  • 제품 버전은 루트 VERSION에서 읽습니다. / The product version comes from the root VERSION file.
  • SDK 공개 저장소와 ZIP의 문서·예제·도구·API 소스를 갱신하고 기존 고지·대응 소스를 보존합니다. 오디오 라이브러리의 대응 소스도 동봉합니다. / Updated SDK documentation, examples, tools and API sources while preserving existing notices and corresponding sources, including audio library sources.
  • 창작마당 패커는 혼합 보이스팩·캐릭터·네이티브 보조 실행 환경과 추가 데이터 형식을 보존합니다. 지원하지 않는 파일이 있으면 일부만 버리고 성공하지 않고 패키징을 중단합니다. / The Workshop packer preserves mixed voice/character packages, native helpers and additional data formats, and rejects unsupported files without producing a partial package.
  • 모든 창작마당 레이아웃의 데이터는 Steam 원본에서 직접 읽습니다. 동의는 출처와 실행 파일 목록·내용을 기준으로 하며, Windows 실행 파일은 내용 복사 없이 잠근 하드링크 경로를 사용합니다. / All Workshop layouts read ordinary data directly from Steam originals. Approval covers executable origins, inventories and contents; Windows execution uses locked hardlinks without copying file contents.
  • native/·audio-native/의 Windows x64 DLL과 plugins/runtime/의 보조 실행 환경을 지원합니다. 보호된 실행 경로에서 상대 폴더 구성을 유지하며, 코드 변경 시 재동의가 필요합니다. / Added support for Windows x64 DLLs under native/ or audio-native/ and helper toolchains under plugins/runtime/. Protected execution views retain relative paths; executable updates require renewed approval.

SDK 1.3.0 · 앱 1.3.0 · api_version 1 — 첫 공개 / First public release

  • 코드 모드는 명시적 동의 후 다음 실행부터 코드와 동봉 데이터를 적용합니다. JAR·라이브러리 변경 시 재동의가 필요하며, 미동의 잠금은 같은 코드 버전의 시작 알림만 제외합니다. ESC/X 닫기는 상태를 바꾸지 않습니다. / Code mods require explicit approval before code and bundled data apply on the next launch. JAR/library changes require renewed approval; declining mutes startup notices for that code version only. Escape/X leaves state unchanged.
  • 동의된 모드별 검증 사본을 실행합니다. 라이브러리는 같은 모드의 plugins/lib에 포함하고 설치 폴더를 CodeSource로 가정하지 마세요. 매니페스트 Class-Path와 JAR 인덱스는 허용하지 않습니다. 공개 API 호환 번호는 1로 유지합니다. / Execution uses verified per-mod snapshots. Bundle libraries under the same mod’s plugins/lib; do not assume CodeSource is the installation folder. Manifest Class-Path and JAR indexes are rejected. Public API compatibility remains 1.
  • PluginContext.beginMicCapture()와 MicCaptureLease 추가. EDT 밖에서 실제 출력 종료를 확인한 뒤 녹음할 수 있으며, 중첩·여러 소유자·종료 자동 반환을 지원한다. / Added a blocking off-EDT capture lease that confirms output closure and supports nested holds, multiple owners and automatic context cleanup.
  • 보유 중 보이스팩·TTS·미리듣기·플러그인 음성은 버리고 나중에 재생하지 않는다. / Voice packs, TTS, previews and plugin voices are discarded during capture and never replayed afterward.
  • PluginTestKit의 가짜 lease와 억제 기록 추가. 이전 앱에는 이 메서드가 없으므로 플러그인은 기능 존재를 확인하거나 대응 호스트와 함께 배포해야 한다. 본체와 SDK의 버전은 1.3.0으로 함께 배포한다. / Added fake leases and suppression records. Older apps lack this method: feature-detect or ship with a matching host. The app and SDK ship together as version 1.3.0.
  • 설정창의 addFeatureToggle 체크 변경은 앱 1.3.0부터 즉시 콜백을 호출한다. / Settings-window feature toggles invoke their change callback immediately in app 1.3.0.
  • SDK ZIP에 index.html과 문서별 HTML 읽기본 추가. 원본 Markdown·라이선스는 그대로 유지하며 API 호환 번호는 1이다. / Added offline HTML readers to the SDK ZIP while preserving the original documents and API compatibility version 1.
  • Workshop 포장과 공개 SDK 저장소 생성은 입력과 출력이 겹치면 쓰기 전에 거부합니다. 재포장은 기존 업로드 정보와 항목 ID를 보존하며, 하위 디렉터리 링크·Windows 정션은 따라가지 않습니다. / Packaging rejects overlapping input/output paths before writing, preserves existing Workshop metadata on repack, and skips directory links and Windows junctions.
  • text()는 같은 이름의 jar가 여럿이어도 자신의 jar에서 언어별 문구를 찾고, sayTo()는 지정한 개체 ID를 말풍선 서비스에 전달합니다. / text() resolves translations within its own archive even when jar names collide; sayTo() preserves the requested mascot ID when dispatching its bubble.
  • API.md 의 표면 전부가 이 버전에서 시작합니다 / The whole surface in API.md starts here.
  • 버전 규칙: SDK 버전은 앱 버전과 같습니다(sdk.json 의 sdk_version = app_version); api_version 은 별개의 API 호환 번호이고 PluginContext.API_VERSION 도 1 입니다; 문서·예제 개정 내용은 배포 안내에서 확인합니다 / Versioning: the SDK version is the app version (sdk_version = app_version in sdk.json); api_version is the separate compatibility number and PluginContext.API_VERSION is 1; see the release notes for documentation and example revisions.
  • 안정·실험: 공개 표면은 안정과 실험으로 나뉩니다. 안정 항목은 같은 api_version 안에서 더해지기만 하고, 실험 항목은 api_version 을 올리지 않고 바뀌거나 없어질 수 있으며(이 파일에 적고 한 앱 버전 동안 빈 자리를 남깁니다) 앱 버전 하나를 바뀌지 않고 넘기면 안정으로 올립니다. 1.3.0 의 구분 기준: 자사 플러그인(LUMI Chat·Super Bongo)이나 앱 자체가 실제로 쓰는 문과 그 짝은 안정, 그 밖은 실험 — 목록은 sdk.json 의 preview, 규칙 전체는 API.md §8. 1.3.0 의 로더는 api_version 을 읽기만 하고 판단하지 않습니다 / Stable and preview: the public surface is split in two. Stable items only ever gain entries within one api_version; preview items may change or disappear without a bump (listed here, an empty slot kept for one app release) and are promoted to stable after surviving one app release unchanged. The 1.3.0 split: doors the first-party plugins (LUMI Chat, Super Bongo) or the app itself use, and their counterparts, are stable; the rest is preview — the list is preview in sdk.json, the full rules are API.md §8. The 1.3.0 loader reads api_version but does not act on it.
  • 이벤트 26 토픽 — ctx.on(topic, handler): ready·behavior·bubble·choice·click·doubleclick·drag·throw·hover·mascot·headpat·affection·achievement·focus·alarm·pomodoro·bongo·settings·app·island·game·chat·tts·ask·settings_open·say_file. 리스너는 플러그인마다 제 스레드(lumi-plugin-events-<id>)에서 돌고, ctx.publish 로 내는 토픽에는 <id>. 이 붙습니다 / 26 event topics — ctx.on(topic, handler): the list above. Listeners run on a thread per plugin (lumi-plugin-events-<id>); topics a plugin publishes through ctx.publish are prefixed <id>..
  • 훅 15개 — ctx.hook(id, (hook, current, ctx) -> …): focus.quiet·focus.screen_busy·text.localized·sound.effect·behavior.force·bubble.duration·bubble.text·selftalk.line·selftalk.interval·speech.greeting·affection.award·affection.tier·place.allowed·bongo.key_frame·bongo.key_input. 모드 탭 순서로 돌고 아래가 이기며 null 은 넘김입니다. 사용자가 건 약속(알람, 사용자가 누른 부탁, say.txt)은 훅으로 막을 수 없고, 앱이 스스로 고르는 것(혼잣말·인사)은 "" 로 건너뛸 수 있습니다 / 15 hooks — ctx.hook(id, (hook, current, ctx) -> …): the list above. Handlers run in Mods-list order, the lower one wins, null passes. Promises the user made (alarms, a request the user triggered, say.txt) cannot be cancelled through a hook; choices the app makes on its own (self-talk, greeting) may be skipped with "".
  • bongo.key_input(안정): frames·look 을 받아 프레임 번호, 직접 입력 대기 -1, 코어 추정 사용 -2/null 을 돌려줍니다. 봉고가 화면에 있는 동안 입력 폴러가 40 ms 주기로 그 스레드에서 부르므로 기다리거나 I/O 를 하지 마세요. bongo.key_frame 도 함께 있습니다 / bongo.key_input (stable): given frames and look, returns a frame index, -1 for provider idle, or -2/null for core inference. A start() that throws gets an immediate stop() and a full release of everything registered through its context (listeners, hooks, hotkeys, menu rows, scheduled tasks); its dependents do not start.
